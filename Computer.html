💻Basic Computer Notes

1. What is Computer?

A computer is an electronic device that takes input, processes data and produces output.

2. What is Hardware?

Hardware means the physical parts of a computer that we can touch, such as keyboard, mouse and monitor.

3. What is Software?

Software is a set of instructions that tells a computer what to do. Examples: Windows and MS Word.

4. What is Internet?

Internet is a worldwide network that connects computers and helps people share information.
